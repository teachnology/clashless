# Tutorials

A short "getting started" series. Read in order:

1. [Preparing your data](01_preparing_your_data.ipynb) — the three input tables `clashless`
   needs, and the rules it enforces.
2. [Creating a schedule](02_creating_a_schedule.ipynb) — solving, understanding the result,
   merging it with your data, visualizing it, and exporting it.
3. [Making schedules compact](03_making_schedules_compact.ipynb) — the optimisation that tries to
   give people fuller free days instead of a few scattered presentations.

Each notebook is independently runnable — you don't need to run an earlier one first.
